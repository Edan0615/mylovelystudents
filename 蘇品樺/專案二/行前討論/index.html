Vue3 + AI 智慧對話 Web App

運用前面 5 堂課學到的 Component 架構、Reactivity 響應式狀態與 Axios 串接，加上第六堂 AI API 實務，打造支援語音、文字輸入與串流輸出的現代化 AI 工具。

  • 支援多輪對話歷史記錄儲存 (LocalStorage)
  • 打字機效果與即時語意高亮渲染
  • 響應式 RWD 介面適配手機與桌面端
AIChatbot.vue 
<script setup>
import { ref, reactive } from 'vue';
import axios from 'axios';

const userQuery = ref('');
const messages = reactive([]);
const isLoading = ref(false);

const sendMessage = async () => {
  if (!userQuery.value.trim()) return;
  messages.push({ role: 'user', content: userQuery.value });
  isLoading.value = true;
  
  // Axios 送出請求至 AI API
  const res = await axios.post('/api/ai/chat', { prompt: userQuery.value });
  messages.push({ role: 'assistant', content: res.data.reply });
  isLoading.value = false;
  userQuery.value = '';
};
</script>
