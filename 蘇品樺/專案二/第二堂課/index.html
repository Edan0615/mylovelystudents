MODULE 01

Vue 是什麼？框架與 JavaScript 的差異

學習前端框架前，必須先了解原生 JS 的手動 DOM 操作與 Vue 數據驅動（Data-driven）的本質區別。

原生 Vanilla JS

imperative 命令式編程

開發者需要親自搜尋 DOM 節點、手動監聽事件、並手動修改 innerText。隨著 UI 變複雜，程式碼容易變得極度混亂且難以維護。

// 手動操控 DOM 範例
const btn = document.querySelector('#btn');
const countEl = document.querySelector('#count');
let count = 0;
btn.addEventListener('click', () => {
  count++;
  countEl.innerText = count; // 必須手動更新!
});
Vue.js 漸進式框架

declarative 聲明式編程 + 響應式 (Reactivity)

只需綁定資料與 HTML 畫面。當數據狀態變更時，Vue 的「響應式系統」會自動精準更新對應的畫面，完全不需手動寫修改 DOM 的繁瑣命令！

<!-- Vue 自動監聽與渲染 -->
<button @click="count++">
  點擊次數：{{ count }}
</button>
💡

用蓋房子形容：「原生 JS」vs「Vue 框架」

原生 JavaScript： 像用鋸子、鐵鎚、磚頭手動打地基蓋房，彈性最大但效率低且耗時。
Vue 框架： 像預製鋼骨鋼筋結構包，提供現代化藍圖與安全地基，讓你心無旁騖聚焦在設計出色的房間 logic 與裝潢！

MODULE 02

瀏覽器的翻譯官：打包工具 Webpack vs Vite

瀏覽器本質上只看得懂最基礎的 HTML, CSS, 和原生的 JS。當我們使用 .vue 單一檔案元件、TypeScript 或 Sass 時，都需要經過「翻譯/編譯」過程。

前端編譯與打包流水線 (Build Pipeline)

1

開發者撰寫原始碼

.vue / .ts / .scss / JSX

2

打包工具 (Vite/Webpack)

編譯、轉譯、轉碼、打包壓縮

3

瀏覽器 (Chrome / Safari)

執行標準 HTML, CSS, JS

Webpack (傳統老字號打包霸主)

Bundle-based Builder
  • 原理： 啟動開發伺服器前，必須先從 Entry 開始「將所有模組抓過來打包成一份 big bundle.js」，再交給瀏覽器。
  • 痛點： 當專案規模變龐大（成百上千個元件）時，每次修改啟動 HMR 需要等待數秒至十幾秒，建置速度較慢。

Vite (法文：快！新世代前端建置神器)

ES Modules + esbuild
  • 原理： 善用現代瀏覽器原生的 <script type="module">，直接由瀏覽器按需請求（On-Demand）載入，底層轉碼採用超快的 Go 語言編寫的 esbuild。
  • 優勢： 毫秒級熱重載（HMR），瞬間啟動開發伺服器！是目前 Vue 3 官方首推的預設工具。
MODULE 03

前端框架演進簡史與現代選擇

從早期的 jQueryDOM 操作時代，到現代的三大框架（React, Vue, Angular），了解前端的演進脈絡。

$
Web 2.0 時代霸主

jQuery

解決舊時代瀏覽器相容性（IE時代）與簡化 DOM 選取（$('#app')）。但在現代單頁應用（SPA）中逐漸被框架替代，新專案已鮮少使用。

Meta 推出 · 全球市占最高

React

強調 JSX 與單向資料流，具有龐大的生態系與社群資源。極度靈活但學習曲線相對較陡峭。

尤雨溪 (Evan You) 打造

Vue.js

主打「漸進式（Progressive）」與極高的親和度，HTML 範本語法上手最快，在全球與亞洲市場極受歡迎。

💡 深度思維討論

AI 時代下：純粹 HTML/CSS/JS 也是好選擇？

現在前端基本上都在使用 React / Vue 進行大型開發，但在生成式 AI（ChatGPT, Claude, Gemini）爆發的時代，開發哲學正在迎來有趣的反思。

人類團隊協作：為什麼需要框架？

人類記憶力有限、溝通成本高，且容易在大型專案寫出泥潭程式碼。框架強制規範了「元件化、狀態管理與寫法標準」，讓數十人的開發團隊能夠依照統一規範進行長期維護。

  • 統一的程式碼架構與模組化
  • 社群成熟的生態系（Router, Pinia）
  • 大型複雜系統的長期維護性
AI 時代：純 HTML/CSS/JS 的逆襲

AI 大型語言模型沒有人類的記憶疲勞問題，能以驚人的速度一次生成或調整數千行原生代碼。對於中小型網站或快速 PoC 驗證，直接使用單一 HTML 搭配純 JS/CSS CDN，沒有 Node.js 依賴過期、打包工具設定複雜的困擾，反而達成最快狠準的開發！

  • 零 Build step，開箱即用
  • 極輕量，瀏覽器直接原生執行
  • AI 寫原生 JS 極度精準且完全可控
MODULE 04

Vue 元件核心：Single File Component (.vue)

在 Vue 中，一個完整獨立的元件（.vue）是由三大靈魂區塊組成：<template>、<script> 與 <style>。

1 <template>

HTML 視圖結構

負責定義網頁骨架與 DOM 結構。在這裡可以直接使用 Vue 特有的模板雙大括號插值 {{ }} 與指令（v-if, v-for, @click）。

2 <script setup>

JS/TS 數據邏輯

元件的大腦！宣告狀態數據（ref/reactive）、計算屬性（computed）、API 請求與函式邏輯。

3 <style scoped>

CSS 外觀樣式

負責元件的視覺裝潢。加上 scoped 屬性後，樣式將「僅作用於當前元件」，徹底解決全域 CSS 命名污染衝突。

MyCardComponent.vue
Vue 3 Composition API 
<script setup>
import { ref } from 'vue';

// 宣告響應式狀態 (Data)
const studentName = ref('品樺');
const score = ref(95);

function addScore() {
  score.value += 5;
}
</script>

<template>
  <div class="student-card">
    <h3>{{ studentName }} 的 Vue 學習成績</h3>
    <p>當前分數：<span>{{ score }}</span></p>
    <button @click="addScore">加分按鈕</button>
  </div>
</template>

<style scoped>
.student-card {
  padding: 1.5rem;
  border-radius: 1rem;
  background-color: #f8fafc;
}
</style>
