10 大評估子題
熱情 學習心得與熱情檢視

從開始接觸程式至今，你覺得自己還喜歡程式開發嗎？一路走來有什麼心路歷程或心得？

（期待聽聽你在寫程式、看到系統成功呈現時的成就感，或是過程中所遇到的挑戰與心態變化）

繪圖 架構繪圖經驗

過去是否曾接觸或使用過 Mermaid 繪圖語法或 ER 圖 (實體關聯圖)？

（在進行系統設計、資料庫架構與流程圖繪製時的習慣與經驗）

框架 現代框架與工具經驗

對於 Vue.js、Laravel 以及 Bootstrap / Tailwind CSS 等框架的學習與實作經驗如何？

（過去是否有接觸過這些主流工具，或是是否有興趣透過本次專案深入實戰？）

1 觀念基礎

對於「物件導向程式設計 (OOP)」的核心概念理解為何？

（如：類別、物件、封裝、繼承、多型在實務專案中的運用）

2 前端技術現況

經過近期/上一次的前端課程後，目前的學習狀態與掌握度如何？

（包含 HTML/CSS 刻劃、JavaScript 原生語法與模組化）

4 AI 輔助開發

平時是否會運用 AI 工具輔助編寫程式？具體的協作流程為何？

（例如：Prompt 生成草稿、Debug 或是進行架構重構）

5-6 全端與資料庫實務

過去開發過哪些全端作品？主要選用的資料庫與 SQL 熟悉度如何？

（如：MySQL/PostgreSQL 經驗，以及撰寫複雜 SQL 查詢能力）

7 架構思考

針對先前提到的「系統效能」議題，你目前的理解與關注點是什麼？

（例如：SQL 查詢優化、前端渲染速度、API 載入時間或架構）

5 大焦點議題
1

學習方向與業界標準

指引往正確或業界標準的方向學習，評估達成接案或就職所需的程度、技能與關鍵知識。透過分享過去業界經驗，協助快速熟悉該領域環境。

2

專業資源與教材推薦

推薦適合促進實戰與理論結合的專業知識、實用工具、優質教材等額外學習資源。

3

接案能力與實務注意事項

了解接案合約內容、合理報價與了解自身行情。包含接案管道建議，以及伺服器、SSL、DNS 等相關概念觀念。

4

專案生命週期掌握

深入理解並熟悉軟體專案從需求分析、設計、開發、測試到上線維護的整體生命週期 (SDLC)。

5

技能補足與系統化學習路徑

過去缺乏系統化學習，面對求職網上多元複雜的技能需求感到迷惘。希望協助梳理優先順序，釐清該如何下手補足。

Step 3 & Step 4 對應：軟體架構能力與 Web App 成品開發

核心課綱：軟體架構能力、SOLID 原則與 Web App 實務成品

4-1 ~ 4-2 架構與實作
4-1 架構培育與 App 成品目標 優良架構 + 實體 App

針對 Junior 階段重點培養軟體架構能力與良好程式習慣（包含 SOLID 原則與 Service Layer 防肥 Fat Controller），並以打造出一個完整的 Web App 系統作為核心最終成品，達成高架構品質與實務展示成果。

4-2 核心技術與成品範疇 完整實務作品
1. SOLID 原則 (Single Responsibility 等) 2. Service Layer 分離 (Anti Fat Controller) 3. 關聯 DB 設計 (RDBMS / ERD) 4. 實體 Web App 成品開發 (Laravel + Vue)
💡 課程重點提示（伺服器與部署相關）： 本課程不進行實際部署的繁瑣步驟操作，而是重點教學網路與伺服器相關核心概念（如：Linux 伺服器架構、SSL 安全憑證設定原理、DNS 域名解析、HTTPS 傳輸等），確保掌握維運全貌而不花費過多時間在純託管設定上。
